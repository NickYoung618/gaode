现场连接与地址映射

IP、端口、站号和 PDU 地址需根据 PLC 工程或厂家设置填写。只有“Modbus”还不能确定 TCP 或 RTU；此版本支持 TCP。

两个 BOOL 共享一个 WORD：例如 MB2000 与 MB2001 都位于 MW1000，但各占一个字节。后端会先读原字，保留邻字节，再写入指定字节。INT 占 1 个字，REAL 占 2 个字。这里只确认内存布局，Modbus 起点仍由现场填写。
