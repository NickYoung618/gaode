# 高德 PLC 可视化联调包 0.4.0

本版是确定地址合入基线：PC.xls 26项、PLC(2).xls 59项，共85项。使用 Modbus TCP。新版 PLC 心跳请求是 **MB6038**，PC应答是 **MB2011**。旧0.3包和旧site.json不能沿用。

## 启动和查看

完整Windows x64包解压到可写目录，双击Start.cmd，浏览器打开 http://127.0.0.1:18765 。自包含程序不需要.NET SDK。保留后台窗口，页面断开后再关闭后台。端口冲突可用 `Gaode.PlcFieldUi.exe --port 18766`。

在“现场配置”填写IP和端口并保存，再点“连接 · 只读监视”。站号默认1，PC/PLC零基PDU起点默认1000/3000，反馈FC03，BOOL EvenLow，REAL Abcd。这些只是可修改的初值；未勾选映射确认也可以读取。日志明确记录未校准，须对照PLC监视值判断解释是否正确。

PC→PLC表显示发送区的实际读值，PLC→PC表显示反馈。每项有MB/MW/PDU、类型、原始字和时间。记录中的TX是发出去的请求，RX是PLC响应，ERROR是失败及已收数据。取消“隐藏轮询报文”可查看所有读取。写入会显示“待发值→PLC写应答→读回”，这只证明通信和读回，不证明机械执行完成。

## 动作与坐标

目标由用户填写，不自动生成坐标。X、Y、检测Z、扫码Z、抓取Z、R均有目标、启动、到位及实际值映射。可以只写目标，也可带入单轴测试。本版保留既有动作参数配置和写入开关：现场填范围、单位、坐标系、容差、期限，开放目标/启动点，再执行。六轴握手码均来自最新表：启动0/1，到位0运动中、1到位、2超时。

用户另行授权的“只填IP端口首页、减少写入/动作配置门槛、通信三层状态界面”正在中控机独立目录开发，见随包的中控机联调包开发提示词.txt；本版只完成地址基线和只读门槛调整，不冒充该界面已完成。

程序默认不写PLC。启动、复位、心跳和运动由明确操作触发。单轴观察须看到本次运动、到位、实际位置满足已填容差，以及启动清零；旧到位不算本次完成。断开不是急停，动作中断开记录未知，不自动重发。

## BYTE和REAL

一个寄存器16位=两个BYTE。例如Rotate_Start MB2000和X_Move_Start MB2001共享一个寄存器。写一个BOOL先读字，保留邻字节后写回；心跳与其他写入共用执行锁。正式协议项目和工具共用BoolByteCodec、Float32Codec。

INT占两个字节，REAL占四个字节。MB6039是未声明填充，不新增业务信号；相邻读请求可能读取包含该填充的完整寄存器。BOOL高低字节与REAL四字节顺序分别设置，异常解释仍保留原始字。
