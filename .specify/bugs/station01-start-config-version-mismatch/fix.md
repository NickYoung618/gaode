### Build and loading-path check

`frontend/src/runtime.js`、正常构建的 `frontend/dist/runtime.js`、隔离桌面输出 `.../Gaode.Station01.Desktop/release/frontend/dist/runtime.js` 的 SHA-256 均为 `8FBB2CB4309839389416F340C615052F623D3270B17EA65441CBBE20420C0082`，不再含具体版本相等比较。`desktop/Gaode.Station01.Desktop.csproj` 从 `frontend/dist/**` 复制资源；`desktop/HostRuntime.cs` 默认优先加载可执行文件同级的 `frontend/dist`，只有显式 `GAODE_FRONTEND_DIST` 才覆盖该路径。

现场仍在运行的 PID 4844 来自 `desktop/bin/Release/net10.0-windows10.0.17763.0/Gaode.Station01.Desktop.exe`，其同级旧 `runtime.js` 哈希为 `3CDD927C72B1B400D023015FBABDA1B53ED17AE341BCFD6D2EEE1E8C8E27D59C`；该实例**没有更新**，未对其点击或替换文件。新旧桌面EXE本体哈希相同，不能用EXE哈希替代内嵌前端资源哈希。`scripts/start-station01-manual-test.ps1` 在不带 `-SkipBuild` 时会先正常构建前端及桌面并核对两份资源哈希，再启动桌面；当前端口/实例仍占用时脚本会拒绝启动。因此下一次独立页面验收须由会话所有者确认旧会话已安全结束，使用无 `-SkipBuild` 的正常入口，并保存新进程路径、实际加载资源哈希及页面证据；本轮不停止其他会话。
