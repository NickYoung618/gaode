# 真实信号时间线、5秒模拟等待、自动跟随新版入口
真实信号独立时间线保存原点表logicalName、MB、前后值、方向、时间与operationId/actionId；READBACK独立标记上次实读值→本次读回值。运动完成后启动1→0读回突出为复位，手工清零仅称清零，不冒充完成。本盘失败后清零记录仍可见。心跳仍在右上角，位置抖动仍在实时坐标卡，模拟事件独立区不混为PLC信号。
7次相机/算法模拟等待各5秒合计35秒；真实轴、翻面、放回判据不变。
当前文件夹只保留两个.cmd和统一Start-PLC.ps1。入口按语义版本排序，只选release.ready.json标记、runtime与启动文件齐全的完整包。新包发布后无需改入口。若当前已有动作则拒绝切换，空闲版本切换保留现场配置及已启用心跳，不发送启动/复位/清零。旧三个别名入口移动到启动脚本备份，不删除旧独立工程。
