# 独立虚拟上位机联调包
以用户最终 PC.xls 与 PLC.xls（内容匹配 PLC(2).xls）为唯一地址来源，26 PC发送点/59 PLC反馈点。Modbus TCP 按可配置块PDU基址+(MB-块MB起点)//2解释。BOOL 1字节、INT 16位有符号、REAL Float32。不得混入旧模板地址。
首页IP/端口即可连接只读轮询全部85点，保留原寄存器与TX/RX。高级初值unit1、PC1000、PLC3000、反馈FC03、BOOL EvenLow、REAL Abcd仅软件初值，现场尚未校准。
点击才写入或启用心跳，不设许可/映射确认等隐藏门槛。真实故障及通信失效明显显示并暂停依赖动作。所有网络读写、心跳、动作使用同一协调队列。
六轴按用户指定映射写目标并读回、启动字节、观察本次运动证据、到位后清零。仅遗留到位1不得通过；坐标误差未配置容差不能宣布验收。操作员记录机械观察。缺参数不编造自动翻面取放链。
Windows x64自包含包，双击CMD打开浏览器，不需Python或.NET SDK。交付源码、表、配置、日志、证据与独立增量包，不覆盖主工程。

实际 Y=11 的 FC16 TX 为 4130 0000，PLC 显示约2.33849e-41。所有PC方向REAL统一采用Cdab交换16位字；BOOL/INT不变。PC目标读回采用写字序，PLC反馈采用独立读字序，保留Abcd待非零现场校准。保留旧realOrder配置作为兼容回退。离线验证11.0、12.5、-3.25及全部REAL字段；发布与启动切换不发送PLC写请求，不自动连接或恢复心跳。来源表地址不变，新增补丁仅修改独立工程。

## 1.0.2 XYZ反馈和实体网卡持久化
所有PLC方向REAL含XYZ、三个Z、R和速度反馈按Cdab解码，发送同为Cdab，BOOL/INT不变。启动初始化从模板补全独立字序；缺少绑定时按同网段在线实体网卡自动识别，优先名为PLC，多个候选不猜测。Meta等HardwareInterface=false不参与候选。高级设置显式sourceAddress优先；保留本机192.168.0.88。每次连接实际socket源/目标地址写入NETWORK_PATH及页面；不改全局路由或代理。启动不连接或写PLC，部署后只读验证。
