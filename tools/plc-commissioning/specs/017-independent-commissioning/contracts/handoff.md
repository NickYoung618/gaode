# 主工程交接关系
主工程目标目录 scripts/communication/plc-field-ui：本包src/app.py对应联调服务与API；src/transport.py对应Modbus传输/编码；src/web/*对应独立联调页面。sources/protocol.json对应最终点表导入结果；config/default.json/local.json对应现场解释配置；本specs目录对应新增规格文档。
本包没有复制或修改客户确认原型、正式前端、另一台机器主工程文件。集成者按增量包清单选择性合入，不整目录覆盖。
实际源地址文件为本包sources/PC.xls与sources/PLC.xls；后者哈希与用户指定PLC(2).xls相同。
现场网络验证仅沿用旧包已存的只读FC03记录，属于历史证据，不能证明最终布局。此次实现期间不连接、不试写真实PLC。
完整包自带隔离的Python解释器与标准库；增量包不含运行库，不是整主工程补丁。

## 1.0.2 XYZ反馈和实体网卡持久化
所有PLC方向REAL含XYZ、三个Z、R和速度反馈按Cdab解码，发送同为Cdab，BOOL/INT不变。启动初始化从模板补全独立字序；缺少绑定时按同网段在线实体网卡自动识别，优先名为PLC，多个候选不猜测。Meta等HardwareInterface=false不参与候选。高级设置显式sourceAddress优先；保留本机192.168.0.88。每次连接实际socket源/目标地址写入NETWORK_PATH及页面；不改全局路由或代理。启动不连接或写PLC，部署后只读验证。
