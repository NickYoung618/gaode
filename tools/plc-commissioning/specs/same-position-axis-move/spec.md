# 已在目标位置的轴

定位前在当前连接、当前动作窗口内重新读取启动、到位和实际坐标；安全状态有效，启动0、到位1且有限实际坐标落入目标容差时，该轴沿用位置，不写目标/启动，不等待运动中。不固定跳过任何轴。
需要移动的轴继续要求本次运动中及到位证据；完成后核对实际坐标并清零。混合轴组仅启动需要移动的轴，最终复核所有相关轴。残留启动、无效反馈、故障、断线及复用位置漂移阻断推进。日志明确区分PositionReused和MotionCompleted。
联调配方使用配方容差；手工使用轴配置容差，未配置时仅允许精确相等复用。实际运动的原握手保留；1.1.4配方已有的坐标完成路径保留但明确记录。
