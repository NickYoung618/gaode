只做受影响构建、必要组件回归、架构门禁和专项收敛，不要求全量npm test、全配方/面数组合或009/010历史专项。必要校验、实际保存失败及受影响边界保护保留；零发现、漏跑、Skip、失败和旧报告如实区分，不能计通过。

原型归档及无关页面保持保护；检查器只定向承接012授权弹窗差异，不关闭旧检查或把错误架构改为正例。旧断言因需求替代时须承接仍有效的保存、关联、取消、期限及历史读取；失败不是删除依据，无效测试实际移除须有消费者/覆盖审计，历史原始证据只读。access token不写日志，证据沿现有artifacts/frontend目录记录，不能使用localStorage/假API/预置成功或测试专用配方冒充正式集成。
