# 已在目标位置的轴

2026-10-08当前设计修订，由[HC-020](../020-real-device-commissioning/contracts/closed-loop-handshake.md)承接，已在020阶段A实现及离线验证，见[实际记录](../020-real-device-commissioning/validation.md)。替代此前“当前启动0、到位1及坐标相同即可沿用”的规则；原版本化validation/tasks不改。

每轴须本连接已有实际到位及双方清零记录，本次重新读取请求0、反馈0、可靠实际坐标及有效设备状态，坐标在目标原容差内，才沿用位置；不写目标/启动、不等Moving、不固定跳过Y或任何Z。全复用和混合轴组均最终复核所有相关轴。

首次连接、重连、已观察复位、未知、安全失效、漂移或其他路径可能移动该轴使旧资格失效。无记录不许直接复用，但不新增首次正常移动必须有上次动作的条件，不自动试走。需要移动的轴保留本次派发后运动/到位及对应实测规则；完成后清PC请求，还须新鲜确认PLC反馈0。

PositionReused用本次复核生成关联当前请求的定位证据，并引用历史完成/清零资格；不能直接返回旧动作证据或宣称新运动。正式与工具的必要差异沿HC/TC：配方原容差、手工复用无容差时仅精确相等；工具1.1.4实际配方完成路径的放宽不推广至正式。
