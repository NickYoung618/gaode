# 虚拟PLC测试监控页面设计
日期：2026-09-29。仅VirtualPlc/wwwroot诊断前端，依003 FR14与virtual-plc-boundary；非006客户操作台，客户原型只读。

## 测试者任务
观察PC发出的真实命令及PLC反馈，停留在任一阶段核查，不被新记录推动；可搜名称/地址/含义/事务或动作，按方向过滤。当前状态和历史证据分开。

## 布局与交互
顶部紧凑标题、真实通信及错误摘要；一行运行概览。主区域历史占主要宽度，侧栏保留完整实时点位，可专注记录隐藏。桌面高度随视窗展开，历史单一滚动区、固定表头，行内显示本地毫秒时间（标题UTC）、方向、地址/信号、真实值及含义；较长关联可展开，不挤占所有行。1366×768和1600×1000均核验，不增加独立XYZ栏目。小屏侧栏隐藏，可明确展开。
默认最新在前；用户向下滚动即暂停查看，后台继续接收，显示新增记录数量；恢复按钮回到最新。搜索/方向过滤作用于所选可见快照，缺口提示不被筛选隐藏。清空仅页面记录，保留审计游标；有限缓存超出有提示。

## 数据和错误
同值解锁从audit writes产生一条真实命令，不从快照补历史、不造前值；被拒绝的写入不得称实际执行。PalletLock动作关联只使用有效writeSequenceRefs；受理/动作completed不代替状态反馈。完整XYZ和状态按既有合同。HTTP读取、PLC心跳、页面显示、审计错误保持分类。暂停查看不暂停采集、不修改PLC状态。所有页面请求GET。

## 必要验收
原上传解锁审计可见；受理/实际反馈可分；重复轮询和清空无重放；原XYZ/方向/错误分类通过；搜索/方向/暂停查看/恢复/专注模式在真实浏览器可用；新包静态资源与源码一致，历史包保留。
