# 015 最小实施计划

## 0.3 增量计划（2026-10-05）

新增独立.NET 10本地后端，发布Windows x64自包含目录；现场无需SDK/Python。沿用0.2归档不覆盖。浏览器仅调用回环HTTP API；后端独占Modbus连接与串行操作锁。复用正式项目Float32Codec源码，新增现场字节布局编解码及FC03/04/06/16通信记录。旧正式适配器暂未接受该点表，回传后更新相关spec/contracts/plan/tasks再接入；本次不伪称全量共用正式握手。
配置schema=2，现场参数空值，不猜地址；保留原始附件和哈希。逐点人工写与自动心跳统一串行；BOOL先读原字再合成并写回，验证邻字节未改。单轴状态机轮询期间不占用整个动作期限，心跳持续；失败不重试、不自动清零。
验证只覆盖主流程所需：真实TCP测试PLC、只读零写、两种BOOL位置/四种REAL顺序、共享字节交错写、显式写入门禁、单轴新运动/到位/实测/清零、异常日志、浏览器按钮和导出哈希。

日期：2026-10-05。仅新增独立通信探针，不修改共享接口、来源、既有功能任务或产品前端。

采用 Windows PowerShell 5.1 脚本和 JSON 点表；无需 Python、.NET SDK 或第三方包。直接使用 TcpClient，按当前 ModbusTcpClient 相同的 MBAP/FC01/03/05 规则实现小范围诊断。此工具不是正式适配器的回归替代；正式软件还须用同一份已确认现场点表完成最终联调。

脚本读Coil/DiscreteInput/HoldingRegister/InputRegister，支持Bool/UInt16/Int16/Float32。开启心跳才允许写PC_Heartbeat_Resp；用户追加后，-AllowMotion并填写确认配置才允许当前轴目标FC16及启动FC05。无通用写入。默认轮询300ms、I/O超时1000ms、心跳变化期限3000ms，不代表设备性能验收。相邻完整点合并读，不跨未配置地址。

终端展示信号表、最近事件和统计；无交互终端采用追加文本。events.jsonl 记录状态/变化/心跳/失败，wire.jsonl 保存每次原始收发及耗时；每条写完刷新。输出 config.snapshot.json、summary.json，所有记录关联 sessionId。有限运行默认60秒，可指定时长，交互按Q结束。异常停止连接，不自动重试写入。

现场模板连接/地址为空，逐点 enabled 控制；只校验启用点。明确的 Virtual 配置仅连回环地址，取当前 Gaode.Plc.Protocol 的测试映射。检查配置与窗口中的来源，不把名称当地址确认。

验证：Windows PowerShell 5.1 运行；必要 TCP 替身测试读解码、分片/错误响应/超时和写限制；构建独立 VirtualPlc 后用真实 TCP 验只读及心跳，再查服务审计。仅运行受影响验证。

单轴增量：配置仅列当前来源的六类轴四信号映射，逐轴填范围/单位/坐标系/容差/期限。心跳、PLC就绪/自动/无故障、启动空闲后受理；先目标后启动，初始运动中局部50ms采样，之后200ms；核0→1后重读实测，再清触发并读回。错误/超时保留未完成动作，不重发或自动清零。现场就绪握手缺失只阻真机动作，不猜规则。

终端非阻塞输入move，保持心跳；-ActionName/-Target为已获操作员允许后的自动单步入口。独立VirtualPlc用真实TCP验证一条X单轴，夹具通过正常Modbus写PC_System_Ready建立测试前提，不加入现场工具入口。
