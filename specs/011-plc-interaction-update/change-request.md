## 4. 共同流程及实现影响

### 4.1 流程记录

1. 人工上料确认并启动，满足本轮已明确的设备动作准入。
2. 到3D采集位置，完成真实采集与算法调用，记录有无、姿态和F码XY定位结果。
3. 按3D定位结果移动至F码位置，扫码、唯一匹配、绑定配方；将槽位观察关联到本盘执行输入。
4. 从配方／点位配置取得检测坐标，执行当前有效槽位的当前面检测。
5. 有下一面时，对仍需检测的相应对象完成翻转和放回，再统一3D复查；异常槽位退出，正常槽位继续。按配方在适用面执行E扫码。
6. 汇总检测结果，只为仍符合自动处理条件的对象生成适用分拣；姿态异常槽位原位保留。
7. 分拣完成后移动到下料位，完成必要记录、状态输出及人工下料交互；返回姿态异常槽号。

首次3D发生在F绑定之前，其采集和观察输入不得依赖尚未识别的同一产品配方而形成循环依赖。具体结果结构、槽位关联方式及配置接入复用现有能力，由后续plan作最小设计。

预算和取消处理沿用已有有效约束。新增3D调用及运动步骤需要定向更新真实工作量和对应期限安排；不猜新数值、不无条件延长期限，不为测试通过取消必要保存或允许取消后后台继续推进。

4. 虚拟PLC通过正式通信路径完成对应交互；媒体、算法和数据库使用本次范围内的实际组件，不直接写假成功或预置最终结果。
5. 取料事实及必要保存的放料门禁、对象和调用关联、取消约束及结构化日志继续保留。新动作细节的保存衔接在plan中明确，不以旧信号删除为由移除业务保护。
