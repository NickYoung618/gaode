## 1. 原型页面对照

1. 从只读 ZIP 读取页面清单和资源清单，不修改压缩包。
2. 启动前端静态预览/构建产物，逐页对照 `login.html`、`a.html`、`data-view.html`。
3. 检查 DOM 结构、文字、字段、控件、布局和交互顺序；记录截图/DOM 差异。
4. 仅012配方弹窗授权差异按新映射核对；其余结构/文字/导航差异仍失败。归档哈希、三页清单及无关区域保护保留，不关闭旧检查或笼统豁免a.html。

## 2. WPF/WebView2 启动

1. 启动桌面程序。
2. 验证 WebView2 Runtime 检查；缺失时应显示宿主受限提示，不显示登录成功或业务数据。
3. 验证资源目录通过 `https://appassets.local/` 加载，禁止 `file://` 任意路径和外部 CDN。
4. 验证默认导航到 `login.html`，关闭窗口可结束 WebView2 生命周期。
5. 在无外部网页服务器、无 CDN 网络时重复启动，三个页面资源仍应加载。

## 3. 登录与权限

1. Test 环境使用后端配置的 Bearer Token，验证四类角色的读取/启动/暂停/取消/恢复/媒体权限。
2. 无认证、过期凭据、401、403 分别验证登录页或原型已有权限提示。
3. 页面不信任请求体中的角色字段，后端拒绝必须优先于按钮状态。
4. 若无生产登录端点，结果记录为 `AuthUnavailable`，不得用前端本地判断模拟生产认证。

## 4. API、状态和 ETag

1. 调用配置校验和启动接口，确认 202 只显示“请求受理”，不显示设备完成。
2. 通过运行查询和 `/status` 读取状态；验证相机/算法/PLC/媒体为 `NotIntegrated`、`NotReady`、`Unknown` 或模拟状态时不显示 Success。
3. 首次 GET 保存 ETag；带 `If-None-Match` 重取并验证 304；发生版本变化时重新读取快照。
4. 断线或请求超时不得自动重复命令；使用原 commandId/requestId 查询确认。
5. 409/429/503、错误 JSON 和 `ErrorContract`/ProblemDetails 均验证为受限错误，不填充虚假结果。

## 5. SignalR 断线和乱序

1. 连接 `/hubs/station01`，验证 `StateChanged`、`DiagnosticChanged`、`HandoffReady` 只触发重取。
2. 注入重复、迟到和乱序通知，确认较低 revision 不覆盖已显示快照。
3. 断开连接，执行有界重连；重连成功后 GET 最新快照，失败时显示 Offline/HostUnavailable。
4. 验证慢客户端不会阻塞页面查询，也不会被通知误导为动作已完成。

## 6. 媒体

1. 只使用后端返回的 `mediaId` 请求 `/media/{mediaId}`。
2. 验证成功流、ETag/304、404/未保存媒体和未知元数据状态。
3. 尝试任意本地路径、目录路径或前端上传，确认不被前端/宿主接受。

## 7. FullSimulation 受限状态

只有受影响组件测试可用模拟后端验证必要受限状态，标明替身范围；正式保存/扫码/执行证据必须实际调用所需组件。不能用预置成功、模拟保存失败响应、localStorage或测试专用配方代替集成事实；不扩展全失败矩阵。
