## 决策 1：客户原型作为不可变页面基线

**Decision**：使用 `E:\dzk\gaode\原型.zip`，SHA-256 `3DC791C1F8AB5EEDFA037F5DBAE450B2D20522FED654F86EA700C0284945E1E0`。归档包含 `a.html`、`data-view.html`、`login.html` 及 `assets/`。

**Rationale**：客户已确认这三个页面的结构、布局、文字、字段、控件和交互流程。除012已授权配方制作弹窗外，前端只绑定后端事实、权限、状态、错误、通知和媒体；不以“优化体验”改无关页面。

## 决策 2：WPF + WebView2 桌面承载 Web 前端

**Decision**：交付 Windows WPF 可执行程序，使用 WebView2 承载 Web 页面。宿主启动时检查 WebView2 Runtime，创建 `CoreWebView2Environment`，将随程序安装的静态资源目录映射到 `https://appassets.local/`，导航到 `login.html`。

**Rationale**：满足 Windows 直接执行、Web 技术开发和本地资源离线加载要求；虚拟主机映射比 `file://` 更适合相对资源、CORS 和安全策略。

**Alternatives considered**：外部本地 Web 服务器、`file://` 加载、直接使用浏览器窗口；均不作为默认生产方案。外部 Web 服务器会引入额外生命周期和端口，`file://` 会增加资源和跨源边界，均与本期桌面宿主目标不符。

## 决策 3：静态资源本地打包，不依赖 CDN

**Decision**：前端构建产物与 WPF 程序一起打包；原型中引用的 Tailwind、字体、图标等外部资源在实现阶段本地化/固定版本，页面结构和交互不变。无网络时页面仍能加载。

**Rationale**：生产环境不能依赖 CDN 或外部网页服务器，且 WebView2 本地资源必须可复现。

**风险与边界**：本地化资源可能造成像素差异；只能通过视觉/DOM 对照发现并记录，不得直接改原型结构。若确需改文字、布局或控件，必须走原型变更流程。

## 决策 4：前端只消费后端事实

**Decision**：HTTP API 获取命令回执、运行快照、状态快照、错误和媒体；SignalR 只作为状态变化提示，收到通知后按 `revision`/`persistedRevision` 重新查询。前端和 WPF 不访问 PLC、相机、算法进程、数据库或后端 Domain/Infrastructure。

**Rationale**：符合 P02/P05/P07/P12，避免 UI 或宿主形成第二个控制入口。命令受理不等于动作完成，通知也不等于物理确认。

## 决策 5：能力未接入时如实显示受限状态

**Decision**：`NotIntegrated`、`NotReady`、`Unknown`、`Pending`、`CommitUnknown`、`HandoffNotReady` 和连接失败均保留来源与原因，前端不映射为 Success/OK/已完成。

**Rationale**：后端当前相机、算法、部分 PLC/存储能力可能是模拟或未接入；模拟流程只能支持软件联调，不能伪装生产事实。

## 决策 6：现有后端接口差异以合同变更记录，不在前端绕过

已核对当前 Host 代码，发现以下差异：

| 差异 | 当前情况 | 前端处理 | 后续合同任务 |
| --- | --- | --- | --- |
| 登录 | 当前主要是 Test Bearer Token，没有独立生产登录 API | 登录页保留原型输入和错误状态；未有端点时显示受限，不伪造成功 | 增加/确认 `AuthContract`，或明确外部认证注入方式 |
| 错误 | 部分路由返回匿名 JSON/ProblemDetails，未全部是 `ErrorContract` | 兼容解析已知错误，未知响应显示通用受限错误并保留 HTTP 状态 | 统一 400/401/403/404/409/429/503 错误合同 |
| 通知 | 已有 `NotificationEnvelope` 类型，但完整事件集合和重取规则需固化 | 事件只触发 GET，按版本丢弃旧通知 | 固化 `StateChanged`、`DiagnosticChanged`、`HandoffReady` 载荷合同 |
| 媒体 | `/media/{mediaId}` 返回流和 ETag，完整 `MediaReference` 不作为独立查询返回 | 只使用已获得的 `mediaId`，缺元数据时显示受限 | 确认媒体引用/状态/来源元数据查询合同 |
| API 基地址 | 由宿主/运行配置决定，前端规格未冻结 | 从只读宿主配置读取，不写设备地址 | 固化 HTTPS、跨源、环境配置和证书策略 |

这些差异不授权本地模拟API或直接访问业务文件。012弹窗的制作/保存使用真实后端读写与目录，消费011共同模型和唯一业务校验；具体结构/签名/存储技术由plan决定，不从旧技术建议推定已确认。
