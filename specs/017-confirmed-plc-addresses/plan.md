# 017 实施计划

使用现有 .NET 10、System.Text.Json、现有 Modbus TCP 客户端及工具页面。共享原始点表作为 Gaode.Plc.Protocol 嵌入资源；独立工具打包携带相同 JSON 和共享字节编解码源码，不引入新服务或依赖。

先归档 XLS 和生成共享表，再扩展 PlcPoint/ProtocolDefinition 的字节布局、共享 Codec 与信号访问器，增加显式 Host 配置入口。工具保留现有配置格式和点击操作，用新版模板和版本校验拒绝旧 Field 布局，更新到 0.4.0。

最小验证：85 项与 XLS 独立比对；新字段/旧虚拟图校验；同字两连接并发写和读取；原有 Definition 准入测试；工具在独立 TCP 寄存器服务下走心跳及 X/R 单轴、坐标、实际反馈、清零、原始报文。只运行有关架构检查和构建。没有实际 PLC 不产生硬件通过结论。

现场仍补协议缺项和生产设备装配。迁移资料追加本轮基线，不覆盖历史核查和验证记录。

装配边界：Host仅传现场Profile路径字符串，仿照已有机械配置路径；文件加载、协议Definition/字序、准入诊断均留在Infrastructure通信层。不得为此次接入放宽009检查规则或把原始协议成员加入Host业务代码。
